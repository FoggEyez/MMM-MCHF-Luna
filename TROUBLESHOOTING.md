# Luna troubleshooting

- If the texture is unavailable, check that assets/moon-color.jpg and the bundled scripts were installed with the module.
- The Moon can be extremely dark near new Moon. Brightness and earthshine are appearance controls; this is not an eclipse simulation.
- Hemisphere changes orientation. autoFit is optional and placement-dependent; choose a fixed diameter if it does not suit your layout.

Use the README for settings, dependencies, privacy and sources. For a bug report, include your device, MagicMirror and Node versions, the observed behavior and a minimal configuration with secrets removed. Do not post private feeds, tokens, precise home coordinates or network snapshots.
